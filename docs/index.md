# AvengerHub

[![CI Status](https://github.com/AY2627S1-CS2103T-F14a-1/tp/workflows/Java%20CI/badge.svg)](https://github.com/AY2627S1-CS2103T-F14a-1/tp/actions/)
[![codecov](https://codecov.io/gh/AY2627S1-CS2103T-F14a-1/tp/branch/master/graph/badge.svg)](https://app.codecov.io/gh/AY2627S1-CS2103T-F14a-1/tp)

![Ui](images/Ui.png)

**AvengerHub is a desktop address book application for CS1101S teaching assistants to manage their students' details.** While it has a GUI, most of the user interactions happen using a CLI (Command Line Interface).

* If you are interested in using AvengerHub, head over to the [_Quick Start_ section of the **User Guide**](UserGuide.html#quick-start).
* If you are interested in developing AvengerHub, the [**Developer Guide**](DeveloperGuide.html) is a good place to start.
